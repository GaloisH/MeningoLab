MLab 脑膜炎病灶标注工具 · 基础版安装包（不含 AI 预标注）。

| 系统 | 下载 |
| --- | --- |
| Windows 10/11 64 位 | `MLab-<版本>-base-windows-x64-setup.exe` |
| macOS（Apple 芯片） | `MLab-<版本>-base-macos-arm64.dmg` |

- Windows：双击安装程序，默认安装到当前用户，无需管理员权限。若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」（安装包尚未做代码签名）。
- macOS：打开 dmg，把 MLab 拖到「应用程序」；首次打开请在「访达 → 应用程序」中右键 MLab →「打开」。
- 使用说明见仓库 README；运行日志位于 Windows `%LOCALAPPDATA%\MLab\logs`、macOS `~/Library/Logs/MLab`。

> 本软件仅供科研与数据标注使用，不用于临床诊断。
